この課題のゴール　ChatServer.java が 8 / 8 passed になる。わざと壊したときのエラーをメモに残し、直した理由と、メッセージが届くまでの流れを説明できる。

この課題でやっていること： 第5回の ThreadedServer.java（③ AtomicInteger の形）を育てて、1人が打った文が、つながっている全員に届くサーバ にします。全員に配る一覧（黒板）を、もう1つ足します。

問2-1　ChatServer.java を作る

完成形

java ChatServer <ポート番号>

引数を省略したときは 40001 を使います。 起動すると、標準出力にこの1行だけ を出して、待ち受けを続けます。

LISTENING port=40001
受け取った行その接続へ返す行ほかの全接続へ送る行
PINGPONG—
ID自分の接続番号（1 から始まる通し番号）—
COUNTいまつながっている接続数（自分を含む）—
TOTAL起動以来の累計接続数—
SAY <文字列>OKMSG <自分の番号> <文字列>
QUITBYE を返してから、その接続だけ 閉じる—
上のどれでもないERR unknown command—
  • 接続番号は、accept() した順に 1, 2, 3, … と振る。切断しても使い回さない
  • 改行は "\n"、文字コードは UTF-8（配布の ThreadedServer.java のまま）。ログはすべて System.err

作り方（7つの手順）

  1. ThreadedServer.java を、問1-2 の ③ AtomicInteger の形にする
  2. エクスプローラーで ThreadedServer.java をコピーし、名前を ChatServer.java にする。中の public class ThreadedServer を public class ChatServer に変える
  3. ★ 課題2 ①（クラスの先頭）に、全員の出口の一覧を足す。ファイルの上に import java.util.concurrent.CopyOnWriteArrayList; も足す
  static final List<Writer> ALL = new CopyOnWriteArrayList<>();   // 黒板：いまつながっている全員の出口
  1. ★ 課題2 ②（handle の中）：while の前で一覧に入れ、while が終わったら（切断でも）必ず外す
    ALL.add(out);
    try {
      （もとからある String line; と while ( … ) { … } を、そのままここに入れる）
    } finally {
      ALL.remove(out);      // 切断しても、例外が起きても、必ず外す
    }
  1. ★ 課題2 ③（handle の下）：全員に配るメソッドを足す
  // 送った本人以外の全員に、msg を1行送る
  static void broadcast(String msg, Writer except) {
    for (Writer w : ALL) {
      if (w == except) continue;
      try {
        w.write(msg + "\n");
        w.flush();
      } catch (IOException e) {
        System.err.println("DROP " + e.getMessage());   // 1人に送れなくても、残りには送り続ける
      }
    }
  }
  1. ★ 課題2 ④（while の中、send(out, reply(line)); の前）：SAY を受けたときの5行
      if (line.startsWith("SAY ")) {
        send(out, "OK");
        broadcast("MSG " + myId + " " + line.substring(4), out);
        continue;
      }
  1. ID と COUNT は、自分で足します。 ヒントは次の3つです
    • 接続番号は、main の accept() の直後に、AtomicInteger の通し番号から1つもらい、serve と handle に引数で渡す（手順6の myId がそれです）
    • COUNT の答えは、手順3の一覧 ALL の大きさ（ALL.size()）。reply の中に、TOTAL と同じ形の1行を足せば答えられる
    • ID は reply では答えられない（reply は myId を知らない）ので、handle の while の中で、SAY と同じように先に答える

こうなれば OK： ターミナルを3枚にして ChatClient を2本つなぎ、片方で SAY hello と打つと、もう片方に MSG 1 hello のような行が出る。
