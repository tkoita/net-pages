フォルダの開き方、Copilot のサインイン、ターミナル、javac → java での実行、Copilot の使い方と、プログラムが分からないときの聞き方（実例つき）。全部を読む必要はありません。下の一覧から、必要な節に直接飛べます。
  • 毎回の授業の最初にやること 英語表示なら開き直す → Copilot にサインイン → java -version を確かめる、の3つ
  • 1　フォルダを用意する その回のフォルダ（net03 など）を作り、配布セットを展開して開く。「信頼しますか？」には「はい」
  • 2　Copilot にサインインする 画面いちばん上の Copilot のアイコン → 「GitHub で続行する」。毎回の授業で必要
  • 3　ターミナルを開く Ctrl ＋ Shift ＋ @。2枚以上の使い方、Ctrl ＋ C で止める
  • 4　Java を作って動かす javac -encoding UTF-8 → java。引数の渡し方。▷ボタンは使わない
  • 4-5　サーバとクライアントを両方動かす 先にサーバ、あとからクライアント。直したら古いプログラムを止めてから
  • 5　Copilot の使い方 授業での決まり、コメント → Tab、Ctrl ＋ I、/explain・/fix
  • 5-6　分からないときの聞き方 必要な人だけ。第3回のコードを使った実例4つ
  • 6　うまくいかないとき 画面に出た文字から探す表。提案が出ない、javac が通らない、Address already in use など
